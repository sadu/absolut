# Absolut Defense Systems

A futuristic concept website for a next-gen defense contractor, built with React, Vite, and Tailwind CSS v4.

## Features

- **Tech Stack**: React 19, Vite, Tailwind CSS v4.
- **Design**: Dark/Light mode, futuristic "Anduril/Lockheed" aesthetic, HUD-inspired visualizations.
- **Typography**: Inter (Sans) and JetBrains Mono (Technical/Code).

## Setup

1.  Install dependencies:
    ```bash
    npm install
    ```
2.  Start development server:
    ```bash
    npm run dev
    ```

## Structure

- `src/components`: UI components (Hero, Navbar, Features, etc.)
- `src/index.css`: Tailwind v4 configuration and theme overrides.
